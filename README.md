# ExploreWorld Travel Website

A responsive travel and holiday enquiry website built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Destination search and Ghana / International filters
- Destination cards with trip duration and clearly labelled indicative pricing
- Save/favourite interaction on cards
- Enquiry form that prepares an email in the visitor's email app
- Accessible labels, semantic HTML and reduced-motion support

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Deploy with GitHub and Vercel
1. Upload all files and folders in this ZIP to your `explore-world` GitHub repository.
2. Commit the files to the `main` branch.
3. In Vercel, import the GitHub repository.
4. Keep the framework preset as **Other** and the build command empty.
5. Set the output directory to `.` (or leave the default if Vercel detects the static site).
6. Deploy.

## Important demo notes
- The destination package prices are illustrative sample estimates, not verified live offers or supplier quotes. Confirm real rates, dates, inclusions and availability before publishing this as a commercial travel agency website.
- The form uses `mailto:` and opens the visitor's email app. It does not save enquiries to a database or send them automatically. Replace `hello@exploreworld.example` with a real business email before launch.
- Destination photographs are loaded from their original online image hosts, rather than embedded in this ZIP. An internet connection is required for the photographs to appear. See `PHOTO-CREDITS.md` for image source notes.
- The international beach and Dubai images are genuine Unsplash-hosted photographs, but the beach photo is illustrative rather than a verified photograph of the exact Zanzibar location. Replace it with a location-verified image before commercial use.
